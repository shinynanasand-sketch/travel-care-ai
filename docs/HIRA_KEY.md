# 공공데이터 인증키 확인 (초간단)

앱의 노란 배너에 `등록되지 않은 서비스키`가 뜨면 **앱이 고장난 게 아니라**  
「이 키로는 심평원 병원/약국 API를 아직 쓸 수 없다」는 정부의 거절입니다.

TourAPI(관광)가 된다고 해서 병원/약국도 자동으로 되는 것은 **아닙니다**.  
서비스마다 따로 신청·연결해야 합니다.

---

## 한 줄 요약

1. 포털에서 **Decoding 키** 복사  
2. 병원·약국 API에 그 키가 **승인**인지 확인  
3. 같은 키를 Vercel `PUBLIC_DATA_API_KEY`에 넣고 **Redeploy**  
4. 사이트에서 **코스 생성을 새로** 하기  

---

## Decoding 키란?

마이페이지 → **인증키 발급현황**에 키가 두 종류로 나올 수 있습니다.

| 이름 | 생김새 | 우리 권장 |
|------|--------|-----------|
| Decoding | `%`가 거의 없음 (`+`, `/`, `=` 가 보임) | **이것을 Vercel에 넣기** |
| Encoding | `%2F`, `%3D`처럼 `%`가 많음 | 넣어도 되지만 혼동되기 쉬움 |

---

## Vercel에 넣는 위치

1. [vercel.com](https://vercel.com) → 프로젝트 `travel-care-ai`  
2. **Settings** → **Environment Variables**  
3. 이름: `PUBLIC_DATA_API_KEY`  
4. 값: 포털 Decoding 키 (앞뒤 공백 없이 전체)  
5. Production / Preview 모두 같게  
6. **Deployments** → 최신 배포 → **⋯ → Redeploy**

---

## 포털에서 “되는지” 보는 가장 쉬운 방법

포털 UI는 자주 바뀌므로, **마이페이지 → 활용신청 현황** 위주로 확인하세요.

1. [data.go.kr](https://www.data.go.kr) 로그인  
2. **마이페이지** → **활용신청 현황** (또는 **오픈API 활용신청**)  
3. 목록에 아래가 **승인**인지:

   - 건강보험심사평가원_**병원정보서비스**  
   - 건강보험심사평가원_**약국정보서비스** (신규 신청분은 반영까지 수 분~수십 분)

4. **인증키 발급현황**에서 Vercel에 넣은 키와 **같은 키**인지 확인  

**샘플 호출(선택):** 각 데이터 상세 페이지의 「오픈API」「상세기능」「미리보기」에서  
`getHospBasisList` / `getParmacyBasisList`에 키를 넣고 실행 → 에러 없이 목록이 오면 성공.

## 앱과의 관계

| 결과 | 의미 |
|------|------|
| 포털 승인 OK + 코스 재생성 후 배너 사라짐/소스 HIRA | 정상 |
| 포털도 `등록되지 않은 서비스키` | 신청·키 연결을 포털에서 먼저 해결 |
| 포털 OK인데 앱만 403 | 키 복사·env·재배포 문제 → Agent에게 알리기 |

배너가 떠도 **카카오로 병원·약국은 표시**됩니다. 여행 기능은 동작하고, 심평원 원문만 못 쓰는 상태입니다.
